# assets

Third-party media for adoken: backgrounds, sounds, video loops, fonts, icons. Every file has an `[[asset]]` entry in [`manifest.toml`](manifest.toml) with author, source page, license, what was changed, and a sha256.

## What may ship

Spec `docs/specs/0007-theming-backgrounds-sounds.md` §9 says adoken ships only original assets, and marketing must not use third-party copyrighted wallpapers. The built-in backgrounds are procedural (`docs/design/tokens.md` §10.5) and the built-in sound packs are synthesized (`docs/design/sound.md` §7). Therefore:

| Folder | `ship` | Use |
| --- | --- | --- |
| `fonts/`, `icons/` | `true` | Bundling planned by `docs/design/tokens.md` §2.8 and §4. Record them in `THIRD_PARTY_NOTICES.md` when they are embedded. |
| `images/` | `true` | Original illustrations generated by the owner (`ai_generated = true`, `LicenseRef-adoken`): the eight Today moods (spec 0017 FR-30) and the onboarding welcome (spec 0001 FR-19). Lossy WebP at 2× their display box, embedded by `crates/ui/src/images.rs`. The prompts are in `images/image-generation-prompts.txt`. |
| `bg/`, `video/`, `sounds/` | `false` | Dogfooding, demo screenshots and videos, test fixtures, and reference for the synth recipes. Never embed them in the binary and never list them as built-ins. |

Before any file is used in public (X posts, adoken.dev), check its manifest entry:
- **Attribution required (CC BY 4.0):** `bg/anime/starry-sky-night.jpg`, `sunset-clouds-dusk.jpg`, and `treetops-canopy-day.jpg` credit "Unicorn Creates (https://unicorncreates.itch.io/), CC BY 4.0". `bg/anime/apartment-corridor-twilight.jpg` credits "wrothsloth (https://wrothsloth.itch.io/urbanbgs), CC BY 4.0". The exact credit line is in each entry's `notes`.
- `CC0-1.0`, `LicenseRef-Unsplash`, `LicenseRef-Pexels`: no attribution needed. Crediting the author is still good practice.

## Layout

| Path | Count | Contents |
| --- | --- | --- |
| `bg/anime/` | 4 | Anime-style painted scenes with no characters. Most are 1920×1080, the largest size their sources offer. |
| `bg/dojo-night/`, `bg/lantern/`, `bg/dusk/` | 4 / 3 / 3 | Dark and warm moods: Kiyochika and Hiroshige prints (CC0), plus Unsplash photos. |
| `bg/dojo-day/`, `bg/ink/` | 4 / 3 | Light moods and sumi-e. `ink/` includes Hokusai's Great Wave (tag `motif:merge-wave`). |
| `bg/accents/<preset>/` | 2 each | One folder per accent preset: `shu`, `ai`, `matcha`, `kin`, `sora`, `sakura` (`tokens.md` §3). |
| `bg/fixtures/` | 2 | Full-resolution images of at least 6000×4000 for spec 0007 AC-5 (tag `fixture:ac-5`). |
| `video/` | 4 | 1920×1080 H.264 loops for v0.2 video backgrounds, with no audio track. |
| `sounds/{ui,notify,ken,onboarding}/` | 58 | 1–3 candidates for every event in `sound.md` §2. Tags: `event:<id>`, plus `pack:dojo` or `pack:arcade`. |
| `fonts/inter/`, `fonts/jetbrains-mono/` | 2 families | Inter: variable TTFs (roman and italic). JetBrains Mono: static Regular, Italic, Bold (embedded as the default code font). Each with `OFL.txt`. |
| `icons/lucide/` | 1854 SVGs | Lucide 1.48.0, with `LICENSE` (ISC, plus MIT for the Feather-derived icons). |
| `images/today/`, `images/onboarding/` | 8 / 1 | Today mood illustrations at 528×352, welcome at 720×480, all transparent WebP. The full-resolution originals are not in the repo; their checksums are in each entry's `notes`. |

The theme folders are tags as well. Each entry's `tags` lists every mood the file fits, so an image in `bg/anime/` can also be tagged `dojo-night` or `sakura`.

## Rules for adding an asset

1. **Allowed licenses:** `CC0-1.0`, public domain (museum Open Access, Commons PD tags), `CC-BY-3.0`/`CC-BY-4.0`, Unsplash (not Unsplash+), Pexels, and Pixabay. Fonts and icons may also be `OFL-1.1`, `ISC`, or `MIT`. A creator's own license (`LicenseRef-<Vendor>`) is allowed only if it explicitly permits commercial use; quote its operative sentence in `notes`.
2. **Never allowed:**
   - NC, ND, or SA licenses, or items with no license.
   - Wallpaper aggregators.
   - Screenshots or fan art of existing anime, game, or film IP.
   - Anything whose license forbids redistributing it as a material: the repository is public, so committing it redistributes it.
   - Anything related to fighting games (`docs/design/ken.md` §8), and announcer or voice audio.
   - Watermarked files, and images whose main subject is an identifiable person.
3. **Images:**
   - Landscape, with an aspect ratio from 4:3 to 21:9. Never upscale.
   - Downscale the long edge to 3840, the app's processing cap (`tokens.md` §10.3). Only `bg/fixtures/` keeps full resolution.
   - JPEG, 4 MB or less (fixtures: 12 MB or less).
4. **Sounds:**
   - FLAC, 48 kHz, 24-bit.
   - Leading silence trimmed, 5 ms fade-in, peak −3 dBFS.
   - Duration limits from `sound.md` §6.
5. **Videos:** H.264, 1920×1080 at most, 30 fps at most, no audio stream, 15 MB or less.
6. Add the `[[asset]]` entry in the same commit. A file with no manifest entry is deleted.

## Verify

```sh
shasum -a 256 assets/bg/anime/starry-sky-night.jpg            # compare with the manifest's sha256
sips -g pixelWidth -g pixelHeight assets/bg/ink/*.jpg          # image dimensions
ffprobe -v error -show_entries stream=codec_name,sample_rate:format=duration assets/sounds/ken/ko-1.flac
ffmpeg -i assets/sounds/ken/ko-1.flac -af volumedetect -f null - 2>&1 | grep max_volume
```

This folder is about 170 MB in plain git (no LFS). If assets keep growing, move `bg/`, `video/`, and `sounds/` to Git LFS before pushing to a hosted remote.
